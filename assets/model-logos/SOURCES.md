# Appendix model logos

These marks identify the developers or families of evaluated models. All
trademarks remain the property of their respective owners. The family mapping
matches the existing leaderboard figure in this repository.

The following PNGs reuse the assets in the repository's `figures/model_logos/`
directory, with transparent margins cropped and the artwork centered on a
256-pixel canvas, as in `figures/plot_completed_model_results.py`:

- `gemini.png`: existing `gemini.png`, published on `gemini.google.com`.
- `openai.png`: existing `OpenAI-black-monoblossom.png`, from OpenAI's official
  2025 logo archive.
- `claude.png`: existing `claude_spark_clay.png`, from Anthropic's press kit.
- `inkling.png`: existing `inkling.png`, published on `thinkingmachines.ai`.
- `muse.png`: existing `muse_meta.webp`, published on `meta.com`; converted to
  PNG for pdfLaTeX.
- `nemotron.png`: eye mark cropped from the higher-resolution existing
  `nemotron_nvidia.png` (bounds 205, 68, 453, 233), published on `nvidia.com`.

`grok.svg` is the unmodified icon supplied by the official Grok website at
<https://grok.com/images/favicon.svg>, retrieved on 2026-10-19. `grok.png` is a
256-pixel rendering of that SVG for pdfLaTeX. The official brand reference is
<https://x.ai/legal/brand-guidelines>.
